# Улучшения продукта: план и прогресс

Цель: сделать SafeHaul умнее, проще и связнее, не делая его больше и сложнее.
Основа: аудит [`audit.md`](audit.md) (на русском) и проверка каждого пункта по коду
[`verification-notes.md`](verification-notes.md) (на английском, для исполнителя).
Проверено на `main` `9e243f6b` (2026-11-04): все 27 пунктов аудита подтвердились, ни один ещё не исправлен;
проверка нашла ещё четыре ошибки (A–D ниже).

Как читать отметки: `[ ]` — ждёт; `[~]` — в работе; `[x]` — сделано и проверено (с PR и тестами);
**Заблокировано** — нужен ваш ответ (вопрос написан рядом); **Пропущено** — не делаем, причина рядом.
«Слито» значит, что изменение в `main` и выложено на Testing. Серверная часть (Cloud Functions) общая, поэтому
она меняется и для Production сразу при слиянии; экраны Production меняются только после вашего выпуска.

## Как идёт работа

- Пакеты по порядку; один пакет — один PR на ветке `claude/hopeful-brown-j6zg6b`. Пакет сливается, когда CI зелёный
  и замечания ревьюера разобраны (ваше решение от 2026-11-04: «меньше веток, сливай без одобрения, когда зелёный»).
- Следующий пакет начинается от `main` после слияния предыдущего, поэтому пакеты не строятся на неслитом коде.
- Правила доступа к базе (`src/firestore.rules`, `src/storage.rules`) без вашего явного разрешения не меняются.
  Задача, которой это нужно, помечается «Заблокировано» с вопросом.
- Каждая задача: причина → исправление → тесты (сначала падающий тест) → самопроверка → повторные тесты →
  документация (`docs/APP_BRIEF.md` в том же PR) → отметка здесь.

## Открытые вопросы к вам (работа по остальным задачам идёт)

- **В1. SMS лидам.** Лидов (кроме формы рекомендаций) о согласии на SMS никогда не спрашивали. Д2 касается анкет;
  лидам авто-SMS по-прежнему уходят, кроме отказавшихся (STOP) — так же, как сегодня. Оставить так? (задача 1.1)
- **В2. PSP-отчёт в DQ-файле.** Хранить приложенный рекрутёром PSP-отчёт в DQ-файле водителя? (задача 2.6)
- **В3. Автонапоминания.** Слать ли подписанту одно автоматическое напоминание на 3-й день? Это письма/SMS за счёт
  компании. (задача 3.5; ручное «Напомнить» делается без этого решения)
- **В4. Кто отправляет запрос прошлому работодателю.** Код разрешает любому сотруднику, описание приложения говорит
  «только админ компании». Что верно? Пока оставляю как в коде.
- **В5. Тексты о законе.** Письмо «нет ответа» по PEV ссылается на §391.23(j) и пишет «все попытки записаны».
  Стоит показать специалисту по соответствию; формулировки сами не меняю.
- **В6. Отправлять ли водителю обязательные формы после анкеты автоматически** сразу после подачи, если он закрыл
  страницу «спасибо»? Пока делаю кнопку «Отправить водителю» в досье. (задача 2.1)
- **В7. Старые копии данных водителей** (`drivers/{id}/pending_updates`). Их больше никто не пишет и не читает; Data
  cleanup уже убирает из них номер SSN. Удалить ли их совсем? Пока ничего не удаляю. (задача 4.5)
