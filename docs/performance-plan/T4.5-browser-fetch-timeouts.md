# T4.5. Stop the Google Sheet import and the envelope PDF download from spinning forever in the browser

[← Plan, progress and owner decisions](README.md) · Checked at commit `11626a6` on 2026-11-03; re-check line numbers against the current `main` before you start.

- **Checklist item(s):** #12 — Set timeouts for external API calls (browser side: Google Sheet import, envelope PDF download)
- **Size:** S · **Pull requests:** 1 · **Depends on:** none · **Owner decision needed:** none
- **Why it matters for users:** If Google Sheets or Storage stalls, a recruiter importing leads from a sheet, or correcting an e-document, sees a spinner that never ends and has to reload. After this task they get an error message after 60 seconds (sheet) or 120 seconds (PDF) and can try again.

## Current behaviour (verified at 11626a6)

- `src/shared/hooks/useBulkImport.js:81-101` `handleSheetImport`: `fetch(exportUrl)` with no limit (`:91`), then `arrayBuffer()` (`:93`) and `parseBuffer` (`:94`); `processingSheet` stays true until the `finally` at `:98-100`. The hook is used by `src/features/company-admin/components/CompanyBulkUpload.jsx:3` and `src/features/campaigns/components/AudienceBuilder.jsx:7`.
- `src/features/signing/utils/envelopePersistence.js:74-82` `hydrateEnvelopeForEdit`: `getDownloadURL`, then `fetch(url)` and `blob()` with no limit; the catch shows 'Failed to load document for editing.' and `setHydrating(false)` runs in `finally` (`:83-88`). Called from `src/features/signing/EnvelopeCreator.jsx:213-216` ("Correct" and "Edit Template").
- The browser pattern already in use is `AbortController` (`src/features/signing/hooks/useAiFieldAssistant.js:155`, `src/features/company-admin/components/modals/pev/useFmcsaEmployerLookup.js:45`); `AbortSignal.timeout` is not used anywhere in `src/`.
- Envelope PDFs are at most 20 MB (`src/features/signing/hooks/useEnvelopeDocumentControls.js:18-19`).
- `src/shared/hooks/useBulkImport.contract.test.js:124-143` pins `fetch` being called with exactly `EXPORT_URL` (`:137`); that file restores mocks in `afterEach` (`:57-60`). `hydrateEnvelopeForEdit` has no unit test, and no Playwright suite opens an envelope for correction: `e2e/lead-intake.spec.cjs` and `e2e/campaign-audience-builder.spec.cjs` reach the Google Sheet method but never fetch a sheet; `e2e/edoc-envelope-creator-shell.spec.cjs` opens the creator without a PDF.
- Vitest runs on happy-dom (`vitest.config.js:13`).

### Values

- Sheet: 60 s for the request and download together (a recruiter's sheet export is small; 60 s is far beyond a normal answer). The timer is cleared before parsing, so a slow parse is never cut off.
- PDF: 120 s (20 MB at about 1.4 Mbit/s).

In `catch`, pass `controller.signal.aborted ? 'Google Sheets did not answer within 60 seconds.
