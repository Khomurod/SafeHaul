# T2a. Page the campaign recipient log and delivery report

[← Plan, progress and owner decisions](README.md) · Checked at commit `11626a6` on 2026-11-03; re-check line numbers against the current `main` before you start.

- **Checklist item(s):** #5 — Paginate API results (sub-part a: campaign results); #23 — Virtualize long lists (context only: confirmed no virtualization is needed)
- **Size:** M · **Pull requests:** 1 · **Depends on:** none · **Owner decision needed:** none
- **Why it matters for users:** A campaign can message up to 2,000 people, but its recipient log (Details) and its Delivery Report show only the newest 200 and never say that more exist, so a recruiter cannot find or check most recipients of a big campaign. The report also hides **Retry Failed Requests** when every failure is older than the newest 200, although a retry would resend to them. After this task both screens say "Showing the newest 200 of N", load the next 200 when asked, and offer Retry whenever any recipient failed.

## Risks and safeguards

- Extra reads: one count per open (one read per 1,000 logs) and one more in the report; Load more reads 200 only on request. A reload after Check delivery re-reads what is shown (up to 2,000), so no stale delivery state stays on screen.
- Page stability: the cursor is `timestamp desc` and the delivery check never rewrites `timestamp`, so rows do not jump between pages. A log written while a running campaign is being paged appears after a reload.
- Search covers loaded rows only; the notice says so.
- Focus: `Button loading` disables the button; `useLoadMoreFocus` puts focus back on it (or on the "All … shown" line), and the browser tests assert it.
- The old "read again on every toast" loop: prevented by keeping `onError` out of the effect dependencies; the toastProvider suite proves it.
- Phone rendering: up to 2,000 rows only if the user presses Load more nine times; if the 412 review shows lag, record it in the PR instead of adding virtualization here.
- Rollback: revert the PR. No data, rules, index or function changed.
